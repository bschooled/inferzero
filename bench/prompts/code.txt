Write a self-contained C++20 implementation of an intrusive doubly linked LRU cache template with O(1) get, put, and erase operations using an open-addressed hash table with linear probing and tombstone reuse. Avoid std::list and dynamic node allocations per insertion by preallocating a fixed capacity arena. After the implementation, write a comprehensive unit test suite in plain C++ using assert() that verifies eviction order, update-in-place promotion, capacity edge cases, and probe chain integrity across deletions.
